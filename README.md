# Sanskrit Verse Audio Visualizer

A web application that visualizes Sanskrit verses with audio feedback, featuring multiple visualization types and interactive controls.

## Features

- Sanskrit text input with Devanagari support
- Audio playback with visualizations
- Multiple visualization types:
  - Waveform
  - Frequency spectrum
  - Circular visualization
  - Particle system
- Color themes (Default, Sunset, Ocean, Forest)
- Responsive design

## Technologies Used

- HTML5, CSS3, JavaScript
- Web Audio API
- Canvas API for visualizations
- Tailwind CSS for styling

## Usage

1. Visit the [Sanskrit Verse Audio Visualizer](https://yourusername.github.io/sanskrit-visualizer)
2. Enter a Sanskrit verse in the text area or use the default verse
3. Play the audio using the built-in controls
4. Choose different visualization types and color themes
5. Adjust sensitivity for more dynamic visualizations
6. Upload your own audio files if desired

## Development

To run this project locally:

1. Clone the repository
2. Open `index.html` in a web browser
